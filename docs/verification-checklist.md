# mumbl 動作確認チェックリスト

## 概要

mumblはAI駆動のジャーナルアプリケーション（TUI）です。本ドキュメントでは以下の機能の動作確認手順を提供します：
- エントリーの作成・表示
- LLMプロバイダー連携（Ollama/Anthropic）
- リアクション生成（バックグラウンドキュー）
- キーボードナビゲーション

---

## 前提条件

### 環境確認
```bash
# Node.js バージョン確認（>= 20.0.0）
node --version

# pnpm バージョン確認（>= 9.0.0）
pnpm --version
```

### Ollama セットアップ（ローカルLLM使用時）

#### Ollama が起動しているか確認
```bash
curl http://localhost:11434/api/tags
```

#### 接続できない場合

**macOS（Homebrewでインストール済みの場合）**
```bash
# Ollama サービスを起動
ollama serve
```

**macOS（Ollama.appを使用している場合）**
- アプリケーションフォルダから「Ollama」を起動

**Ollama がインストールされていない場合**
```bash
# Homebrew でインストール
brew install ollama

# サービスを起動
ollama serve

# 別のターミナルでモデルをプル
ollama pull qwen2.5-coder:7b
```

#### Ollama なしでテストする場合
Anthropic APIキーがあれば、Ollamaなしでもアプリをテストできます：
```bash
ANTHROPIC_API_KEY=your-key pnpm dev -- --provider anthropic
```

### ビルド確認
```bash
cd /Users/shin/src/github.com/shimpeiws/mumbl

# 依存関係インストール
pnpm install

# 型チェック
pnpm type-check

# リント
pnpm lint

# ビルド
pnpm build
```

## 動作確認手順

### 1. アプリケーション起動

#### 1.1 デフォルト起動（Ollama）
```bash
pnpm dev
```
- [ ] アプリが正常に起動する
- [ ] リストモードで表示される
- [ ] ModeIndicator に「List」と表示される
- [ ] HelpFooter にキーボードショートカットが表示される

#### 1.2 Anthropic プロバイダーで起動
```bash
ANTHROPIC_API_KEY=your-key pnpm dev -- --provider anthropic
```
- [ ] Anthropic プロバイダーで起動する
- [ ] エラーなく動作する

#### 1.3 カスタムモデルで起動
```bash
pnpm dev -- --model llama3.2:3b
```
- [ ] 指定したモデルで起動する

---

### 2. エントリー作成（Write Mode）

#### 2.1 Write モードへの切り替え
- [ ] `Tab` キーで Write モードに切り替わる
- [ ] ModeIndicator が「Write」に変わる
- [ ] テキスト入力エリアが表示される

#### 2.2 エントリー入力
- [ ] テキストを入力できる
- [ ] 文字カウンターが更新される
- [ ] `Backspace` で文字削除できる

#### 2.3 エントリー保存
- [ ] `Enter` でエントリーが保存される
- [ ] リストモードに戻る
- [ ] 新しいエントリーがリストに表示される

#### 2.4 Write モードのキャンセル
- [ ] `Escape` または `Tab` でリストモードに戻る
- [ ] 入力中のテキストは破棄される

---

### 3. エントリー一覧（List Mode）

#### 3.1 エントリー表示
- [ ] エントリーが日付でグループ化されて表示される
- [ ] 各エントリーにタイムスタンプが表示される
- [ ] 長いテキストは適切にトランケートされる

#### 3.2 キーボードナビゲーション
- [ ] `↑` `↓` キーでエントリー間を移動できる
- [ ] 選択中のエントリーがハイライトされる
- [ ] リストの先頭/末尾で適切に停止する

#### 3.3 エントリー詳細表示
- [ ] `Enter` キーで詳細ビューが開く
- [ ] エントリーの全文が表示される
- [ ] リアクションが表示される
- [ ] `Escape` でリストに戻る

#### 3.4 空の状態
- [ ] エントリーがない場合、EmptyState が表示される

---

### 4. リアクション生成

#### 4.1 自動リアクション
- [ ] 新規エントリー作成後、リアクションが自動生成される
- [ ] QueueIndicator にタスク状態が表示される
- [ ] リアクションがエントリーに紐付けられる

#### 4.2 リアクションタイプ
- [ ] デフォルトリアクション（read, heard, thinking, with-you）が生成される
- [ ] LLM 利用可能時はカスタムリアクションが生成される

#### 4.3 バックグラウンドキュー
- [ ] リアクション生成がUIをブロックしない
- [ ] キューステータス（pending, running, completed, failed）が表示される
- [ ] 失敗時にリトライが行われる

---

### 5. LLM プロバイダー

#### 5.1 Ollama 接続
```bash
# Ollama が起動していることを確認
ollama list
```
- [ ] Ollama に接続できる
- [ ] チャット機能が動作する
- [ ] ストリーミングレスポンスが動作する

#### 5.2 Anthropic 接続（オプション）
- [ ] APIキーが設定されている場合、接続できる
- [ ] フォールバック動作が正しく機能する

#### 5.3 設定の優先順位
1. CLI引数 > 2. 環境変数 > 3. 設定ファイル > 4. デフォルト
- [ ] CLI引数が最優先される
- [ ] 環境変数が次に優先される
- [ ] `~/.mumblrc` の設定が読み込まれる

---

### 6. アプリケーション終了

#### 6.1 正常終了
- [ ] `q` キーでアプリが終了する
- [ ] `Ctrl+C` でアプリが終了する
- [ ] バックグラウンドタスクが完了を待つ（graceful shutdown）

#### 6.2 データ永続化
- [ ] `~/.mumbl/mumbl.db` にデータが保存されている
- [ ] 再起動後もエントリーが保持されている

---

### 7. テスト実行

```bash
# ユニットテスト
pnpm test:unit

# 統合テスト
pnpm test:integration

# E2Eテスト
pnpm test:e2e

# カバレッジ付きテスト
pnpm test:coverage

# CI全チェック
pnpm ci:all
```

- [ ] 全テストがパスする
- [ ] カバレッジが70%以上である
