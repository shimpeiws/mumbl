# mumbl

An AI-powered communication tool.

## Status

This project is in early development.

## Development

### Prerequisites

- Node.js >= 18.0.0
- pnpm >= 9.0.0

### Setup

```bash
pnpm install
```

### Available Scripts

```bash
# Development mode with watch
pnpm dev

# Type checking
pnpm type-check

# Lint code
pnpm lint

# Format code
pnpm format

# Build
pnpm build
```
